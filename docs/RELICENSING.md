# Relicensing record

The SDK changed from GPL-3.0-only to Apache-2.0 beginning with release `0.6.0`. Earlier releases retain
their original GPL-3.0-only terms.

Before the change, the complete repository history was audited with `git shortlog -sne --all`. Every
commit was attributed to Tyler Wanner through either a personal email or the `TylerWanner` GitHub
noreply identity. No contribution was attributed to another author.

The `0.6.0` licensing change and NOTICE therefore name Tyler Wanner based on the repository's evidenced
authorship. They do not assert an undocumented copyright assignment to a separate corporate entity.
